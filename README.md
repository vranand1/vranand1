## Research code (public)

- **[pandemic-ui-card-data](https://github.com/vranand1/pandemic-ui-card-data)**: can public card data see the spending drop from ending pandemic unemployment benefits early? Staggered difference-in-differences across 48 states, 140 border-county pairs, randomization inference, minimum detectable effects, and an audit folder with Monte Carlo tests and an independent re-implementation. Companion to [this post](https://vranand1.github.io/2026/10/17/pandemic-ui-withdrawal-card-data.html).
